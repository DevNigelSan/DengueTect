How to read this page
Color Grid Each column represents one week from {% if prov.n_syn %}{{ years[0] }}{{ prov.real_years[0] }}{% else %}{{ years[0] }}{% endif %} to {{ years[-1] }}. Each row is a barangay. The color of each cell shows how many dengue cases there were that week — green means few or no cases, red means a high number of cases.{% if prov.n_syn %} Faded, striped cells are synthetic weeks; solid cells are recorded weeks.{% endif %} Hover over any cell to see the exact week and case count.
Geographic Map The map below shows the same data geographically. Each barangay polygon is colored based on its dengue case count for the selected week. Use the slider or arrow buttons to move through the weeks and observe how risk shifts across barangays over time.{% if prov.n_syn %} A purple notice appears on the map whenever the selected week is synthetic.{% endif %}
Year Summary The cards at the bottom show the total dengue cases per barangay for each year.{% if prov.n_syn %} Recorded years and synthetic years are shown in separate groups.{% endif %}
